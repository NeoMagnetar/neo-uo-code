# Implementation Scope

## Purpose
This section maps the portable arena rules framework into implementation-facing planning.

## Phase 1 boundary
Phase 1 is the phase 1 enforcement shell only. It should cover region boundary awareness, no mounts, no recall, no gate travel, entry and exit handling, and rules messaging.

## Explicit exclusions
Phase 1 does not yet include team logic, scoring, death and respawn systems, lane structure, scripted objectives, or a full arena game loop.

## Region note
Britain graveyard is the first arena region instance used for testing. It is not the permanent naming model for the framework.
