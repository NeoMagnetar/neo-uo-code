# Arena Test Checklist

## Compile safety
- New planning surfaces should compile cleanly when code work begins.
- Arena law work should avoid breaking unrelated region behavior.

## Behavior checks
- Entry handling works as expected.
- Exit handling works as expected.
- No mounts enforcement behaves consistently.
- Recall and gate travel are blocked inside the arena region.
- Rules messaging is clear and not misleading.

## Regression awareness
Any future arena law changes should be checked against ordinary travel and region behavior outside the arena.
