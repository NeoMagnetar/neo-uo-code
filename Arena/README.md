# Arena

The Arena section is the implementation-facing home for the portable arena rules framework.

The system should be built as reusable law and region infrastructure. The Britain graveyard test region is only the first arena region instance, not the permanent identity of the system.

Phase 1 is limited to the phase 1 enforcement shell and should not be presented as full gameplay mode logic.

## Navigation
- `00_scope` defines implementation boundaries.
- `01_rules` defines rule enforcement surfaces.
- `02_profiles` defines reusable rule-set planning.
- `03_regions` defines concrete arena region instances.
- `04_modes` reserves future gameplay extension layers.
- `05_testing` defines verification and regression checks.
- `06_backlog` captures deferred code topics.
