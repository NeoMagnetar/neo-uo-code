# AIGM Script Lane

This directory is the beginning of the long-term AIGM implementation lane inside `neo-uo-code`.

## Current state

The current live shard import was first preserved as a dated snapshot under:
- `../aigm-snapshot-2026-05-29/`

That snapshot should be treated as the exact captured implementation reference from the live NeoUO dev shard on 2026-05-29.

## Purpose of this lane

This `aigm/` directory is intended to become the stable home for curated AIGM implementation surfaces once they are promoted out of snapshot form.

## Intended structure

- `Commands/`
- `Core/`
- `Gumps/`
- `Mobiles/`
- `Interfaces/`
- `Notes/`

## Rule

Promote only intentional, reviewed AIGM surfaces here.
Do not treat this directory as a blind mirror of the entire shard tree.
