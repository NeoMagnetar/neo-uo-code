# Armor Implementation Overview

## Workflow
1. Audit base armor classes.
2. Audit family file locations.
3. Compare with the matching Neo UO design page.
4. Choose the smallest safe prototype.
5. Test the result.
6. Record what changed and what was learned.

## Rule
Do not guess implementation truth when it has not been confirmed. Unknowns should stay explicit until the audit reaches real code surfaces.
