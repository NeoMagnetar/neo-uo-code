# Skill Implementation Overview

## Workflow
1. Audit enum or class references for the skill.
2. Audit likely implementation files.
3. Compare the code surface with the matching Neo UO design page.
4. Choose the smallest safe prototype.
5. Test the result.
6. Record what changed and what was learned.

## Rule
Do not guess implementation truth when it has not been confirmed. Unknowns should remain explicit until the audit reaches the code surface.
