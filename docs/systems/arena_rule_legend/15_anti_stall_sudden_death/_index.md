# Anti-stall and sudden death

Anti-passivity and match-closure pressure systems for long fights, including sudden death, hard caps, mounting restrictions, reveals, and shrinking safe areas.

## Scope

This chapter governs how stalled matches escalate toward conclusion and how the arena changes over time to force resolution.
