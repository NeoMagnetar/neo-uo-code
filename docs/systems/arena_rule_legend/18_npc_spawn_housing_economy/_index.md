# NPC, spawn, housing, and economy

Sterility and economy-neutrality rules for the arena footprint. This chapter keeps world systems from leaking into controlled combat space.

## Scope

This chapter governs housing prohibition, spawn suppression, vendor/bank/harvest restrictions, NPC pathing, and placement of reward vendors outside the ring.
