# Phase64D1D Button-ID Map

- `0`: Close
- `100-199`: Family expand, collapse, and select
- `200-399`: Operational NeoStack expand, collapse, and select
- `400-899`: NeoBlock reference select
- `900`: Operator and Architect mode toggle
- `901`: Back to main organizer
- `1000-1004`: Move Up, Move Down, Move Top, Move Bottom, Move To Stack
- `1100-1101`: Enable or Disable, Lock or Unlock
- `1200-1204`: Add Stack, Rename Stack, Add Block page, Remove Reference, Filter
- `1300-1304`: Preview, Why, Capability, Conflicts, Provenance
- `1400-1403`: Versions, Rollback, Reload, Clear Compare
- `1500-1505`: Save Draft, Approve Preview, Cancel, Confirm Cancel, Confirm Reload, Confirm Remove
- `1600-1601`: Previous and Next page
- `1700-1701`: Composer and Backpack
- `1800-1899`: Secondary page row selection
- `1900-1999`: Version row selection

Button-supplied indexes are never authoritative. The Gump resolves them through stable IDs stored in the current edit session and revalidates before action.
